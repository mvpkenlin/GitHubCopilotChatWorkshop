# GitHubCopilotChatWorkshop
In this workshop, you will learn how to use GitHub Copilot to explain and improve code. GitHub Copilot Chat allows you to interact with AI through a chat experience. Please take this opportunity to learn how to use GitHub Copilot through this workshop.

## Copilot - Intermediate Task 1: Justification

This repository is aligned with the **Copilot - Intermediate** proficiency focus because it supports hands-on practice across:

- GitHub.com collaboration workflows (chat, pull requests, and review-oriented usage)
- IDE-oriented Copilot workflows (chat, suggestions, and iterative coding)
- Prompting and context management habits to improve response quality
- Practical task completion (writing, debugging, testing, and documentation)
